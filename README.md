# Into the Wild — Forest Portfolio

An interactive React portfolio concept using the supplied watercolor rainforest artwork as its hero environment.

## Run locally

Requirements: Node.js 20.19+ (or a compatible recent Node release) and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. To create a production build:

```bash
npm run build
npm run preview
```

## Customize before publishing

- Update the project list in `src/main.jsx` (descriptions, tags, and repository links).
- Replace the generic LinkedIn URL with your profile URL.
- Review the trainee timeline and contact email.
- The supplied artwork is `public/forest-watercolor.png`.

## Interaction

- Scroll navigation to each section.
- Expand each project row to reveal details and repository links.
- Mobile navigation menu.
- Subtle entrance animations, reduced-motion support, and responsive layouts.

This is a frontend starter project. It has not been deployed to a public URL.
